# FocusFlow — Student Productivity & Personal Life Planning System

FocusFlow is a student-focused productivity web application designed to help users organize tasks, goals, and milestones in one place.

The project is being developed as a learning and portfolio project while exploring modern web development, cloud databases, authentication, and productivity-system design.

## 🚀 Current Features

### Task Management
- Create and manage tasks
- Task categories
- Priority levels
- Due dates and times
- Notes
- Task completion tracking
- Progress calculation
- Task reminders foundation
- Recurring task foundation

### Goal Management
- Create personal goals
- Goal descriptions
- Categories
- Deadlines
- Available time
- Current skill level
- Preferred days
- Goal progress based on linked tasks

### Milestone Management
- Create milestones under goals
- Add milestone descriptions
- Target dates
- Link tasks to milestones
- Automatic milestone progress calculation
- Delete milestones safely

### Account & Cloud Foundation
- Supabase authentication
- Email-based account creation
- Login and session persistence
- Supabase PostgreSQL database
- User profiles
- User-specific goals, milestones, and tasks database structure
- Row Level Security enabled
- Initial cloud synchronization layer
